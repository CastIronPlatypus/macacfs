Implementation of lib/prereq.sh; it [[fb-lib-prereq|serves|lib/prereq.sh is the file that bead names, so prereq_ensure and prereq_warn_newproj must be defined there or bin/macacfs fails to source them.]]. It defines ensure_homebrew (non-interactive official installer, then brew shellenv for Apple Silicon or Intel), ensure_git, ensure_go/uv/node, ensure_minisign and ensure_flock (brew formulas via _ensure_brew_pkg), ensure_rust (rustup, then sourcing ~/.cargo/env), all DRY_RUN-aware, and prereq_ensure, which always ensures Homebrew and git, adds rust for cargo-git, go for go, and rust, go, uv, node, minisign and flock whenever any installer-sh tool is selected, reports what it installed, warns loudly on stderr about anything it could not provide, and always returns 0 so each dependent tool fails loudly at its own step. Its method matching [[fb-manifest-tsv-impl|couples-with|prereq_ensure pattern-matches the literal method names cargo-git, installer-sh and go from the manifest's method column, so renaming a method there silently drops its toolchain.]]. It also defines prereq_warn_newproj, which bin/macacfs calls before exec'ing newproj: it prints one stderr note naming whichever of gh (brew install gh), ru and br (macacfs install ru|br) and python3 >= 3.9 (brew install python) is missing, never installs anything and always returns 0, because each of those is needed only by some newproj paths, which [[fb-lib-newproj-core-impl|couples-with|The python3 >= 3.9 probe here must match newproj_python's, otherwise the note would contradict the reviewed bootstrap's own error.]] fail loudly on their own.
