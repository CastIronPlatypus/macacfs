main <command> [args...] routes the command (default help): install and update parse dry-run, call run_tools and, with no selectors, shell_run install or refresh, exiting with the combined code; self-update sets DRY_RUN and calls selfupdate_run; schedule maps --install (default), --uninstall and --status, exiting 2 on others; _tick calls schedule_tick; newproj and new call prereq_warn_newproj and then exec "$BASH" lib/newproj/newproj.sh with the remaining arguments; config calls config_main and exits with its status; list prints the catalog; version and help print text; unknown commands print usage and exit 2. Every mutating branch first calls require_darwin. Within the flow it [[lf-cli-dispatch|serves|main is the routing step of this flow, so without it no verb would reach its handler.]]. It is defined in the file boundary it [[fb-bin-macacfs|serves|main must stay in bin/macacfs because the ~/.local/bin symlink and the LaunchAgent invoke that file.]], and its code is [[fb-bin-macacfs-impl|accomplished-by|main's code lives in the bin/macacfs implementation, so a change to its branches requires re-proving that node.]]. It [[fn-require-darwin|calls|Every mutating branch calls require_darwin first, so on Linux install, update, newproj and _tick exit before touching anything.]]; it [[fn-parse-dry-run|calls|install and update must split --dry-run from the selectors, otherwise --dry-run would be treated as an unknown tool.]]; it [[fn-run-tools|calls|install and update depend on run_tools for every selected tool, so its exit code decides theirs.]]; it [[fn-shell-run|calls|Only a full install or update calls shell_run, so 'macacfs install BR' cannot rewrite ~/.zshrc.]]; it [[fn-selfupdate-run|calls|self-update calls selfupdate_run with DRY_RUN set, so --dry-run must not fetch or reset the repo.]]; it [[fn-schedule-install|calls|schedule with no option or --install calls schedule_install, which must write and load the plist.]]; it [[fn-schedule-uninstall|calls|schedule --uninstall calls schedule_uninstall, which must unload and remove the plist.]]; it [[fn-schedule-status|calls|schedule --status calls schedule_status, which must only read state and never load anything.]]; it [[fn-schedule-tick|calls|The internal _tick verb calls schedule_tick, so the plist's ProgramArguments must name _tick or the scheduled run never happens.]]; it [[fn-catalog-rows|calls|list prints catalog_rows as a table, so a malformed manifest row would show up there first.]]; it [[fn-usage|calls|help and any unknown verb call usage, and an unknown verb must also exit 2.]]. Its newproj branch [[lf-newproj-dispatch|serves|main's newproj|new branch is the entry step of the newproj dispatch flow, so removing it makes the verb fall through to usage.]] and [[fn-prereq-warn-newproj|calls|newproj prints missing-helper notes before the exec, because after exec nothing in bin/macacfs runs.]]; its config branch [[lf-config-verb|serves|main's config branch is the entry step of the settings flow, so without it 'macacfs config' would print usage and exit 2.]] and [[fn-config-main|calls|config hands every remaining argument to config_main, so its exit code becomes macacfs's.]].
