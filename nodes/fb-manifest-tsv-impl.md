A commented header documents the columns and method values, followed by 42 tab-separated tool rows (abbr, repo, cli, method, ref, args, with '-' for no args; the cli column may list alternatives as a|b, first found on PATH wins): 15 brew rows from dicklesworthstone/tap, 3 Homebrew-core brew rows (GUM gum, GLOW glow, JQ jq, whose repo column names charmbracelet/gum, charmbracelet/glow and jqlang/jq and is unused by the brew method), 19 installer-sh rows, 3 cargo-git rows and 2 skip rows (no go rows at present). The skip rows, SRPS and RP, carry their Linux-only reason in the ref column (apt-get/ananicy-cpp/sudo; iptables/ipset and Linux socket APIs). The BRENNER row passes --skip-ntm --skip-cass --skip-cm so brenner's installer does not drop pinned older ntm/cass/cm copies into ~/.local/bin ahead of the Homebrew-installed NTM, CASS and CM rows, and the WA row (cli ft, args --force because that installer exits 1 on its already-installed path) uses ref @latest-release/install.sh, the installer published with frankenterm's latest release, because main's installer refuses that release's single-binary archive (signature repair still runs afterwards). The PI row lists cli pi-rust|pi and passes --yes --keep-existing-pi, because pi_agent_rust's installer otherwise prompts and, when a TypeScript pi exists, installs as pi-rust; [[fb-lib-pathcheck-impl|couples-with|row_cli_resolved in lib/pathcheck.sh is what splits the a|b cli column, so the separator here must stay |.]]. Its column order [[fb-lib-catalog-impl|couples-with|lib/catalog.sh reads these six columns by fixed awk position, so the column order here is a contract with its row accessors.]]. Its method column is mirrored by [[fb-readme-impl|couples-with|README.md's per-method table names each row by abbr, so adding or re-methoding a row here requires editing that table.]].
